# ADR 001 — Isolate architecture evaluation from cloud provisioning

**Status: accepted.** Standardize scenario/profile/fixture independent of the deployment target. The first comparison uses deterministic injected failures to prove scoring and retry plumbing, not to claim LLM success or AWS superiority. Real-agent HTTP evaluations and, later, AWS deployments may share the workload. The cost estimator is a transparent partial estimate; cloud billing is separate. This protects experimental validity and keeps the default workflow free.
