# ADR 002 — Portable agent capabilities with explicitly different local and AWS providers

**Status:** Accepted architecture; AWS realization planned.

**Problem:** AWS agent services are proprietary and cannot, as a whole, be cloned locally. Rebuilding all AWS control planes is prohibitively expensive and would distort architecture benchmarking.

**Decision:** Keep the application's model, memory, tool, retrieval, policy, and trace contracts portable. Run real local substitutes to verify task behavior. Map the same logical contracts to managed Bedrock/AgentCore services in an explicitly separate enterprise target. Document fidelity and maintain conformance tests.

**Consequence:** Functional/behavioral testing can run without AWS spending. This does not establish scale, billing or managed security equivalence. A cloud variant may need provider-specific semantics and must report them.

**Initial implementation:** Dockerized Python service + Ollama + SQLite memory + lexical search + deterministic tool allowlist. The AWS target currently provides a mapping *plan only*; the existing CDK queue stack is not falsely presented as an AgentCore agent deployment.
